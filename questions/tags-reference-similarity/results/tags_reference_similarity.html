33× more likely

A cited cable shares at least one TAGS code with its citing cable 97.4% of the time — versus 12.5% for two random cables. Mean Jaccard similarity of their TAGS sets is 33× higher than chance, and the effect holds across every code type tested.

Method

  1. 01
    Join. tags.norm.ndjson (TAGS per cable) is joined to reftel.norm.ndjson (each cable's extracted REF: citations) on the normalized document number, across all seven years combined — citations cross year boundaries.
  2. 02
    Pairs. Every citing cable with at least one reference that resolves to another tagged cable forms one citing–cited pair.
  3. 03
    Similarity. Jaccard similarity of TAGS code sets, |A∩B| / |A∪B|, computed on the full set and on each TAGS type separately: subject, geographic, organization, person, and three catch-all buckets.
  4. 04
    Null baseline. For every real reference, a random other cable is drawn and compared to the same citing cable — a matched control, not a corpus average.
  5. 05
    Per-code lift. For frequent individual codes, P(cited also has code | citing has code) is compared, actual vs. random, to find which specific codes carry no signal.

Where the signal is weakest

The lift ratios above look enormous everywhere, but two different effects can make a type or code look strong when it isn't the whole story — worth separating before trusting a headline multiplier.

Annotation quotes the highest lift in the corpus (9250×) yet ranks last for reliability — its random baseline is nearly zero, so even a modest 20.9% actual hit rate produces a huge ratio. Read lift and absolute rate together, not lift alone.

Conclusion

The hypothesis holds: cables that cite each other share TAGS at rates 20× to over 1000× above chance, and no type or individual code contradicts it. The strongest, most reliable signal is the subject code set — topical aboutness, not geography — where 92% of real reference pairs share at least one code and 62% share the exact same subject-TAGS set. Geography and organization codes carry strong signal too. The weakest evidence comes from a handful of extremely common codes (chiefly US and broad buckets like PFOR/PINT/OVIP) whose high baseline frequency erodes their discriminating power, and from the noisier person, unknown, other, and annotation buckets, where the signal is real but present in only a minority of pairs.
